# shared (`@btx24/shared`)

**Назначение:** типы контрактов API и чистые функции, общие для api и web.

**Инварианты**
- Без runtime-зависимостей и без Node/DOM-специфичных API.
- api/web импортируют собранный `dist` — после изменений: `npm run build -w @btx24/shared`.
- Каждый новый файл реэкспортируется из `src/index.ts` (общий файл — правки аддитивные).
