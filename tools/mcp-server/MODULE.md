# mcp-server

**Назначение:** навигация агентов по репозиторию и read-only диагностика стенда (Docker, логи, БД).

**Инварианты**
- Ни один инструмент не изменяет файлы, контейнеры или данные. `annotations.readOnlyHint = true`
  у всех; это проверяет `test/mcp-protocol.spec.mjs`.
- Любой путь — через `resolveInRepo`, любой текст наружу — через `redactSecrets`.
- stdout сервера — только протокол MCP; диагностика — в stderr.
- Значения из `.env` наружу не отдаются (даже в ошибках).

**Подводные камни**
- Индексатор регулярный: декларации ищутся только на верхнем уровне или с `export`;
  `endLine` — по балансу скобок, может ошибаться на экзотическом синтаксисе.
- `db_query` ограничивает выдачу через `sql_select_limit` (действует на SELECT верхнего уровня);
  для `SHOW`/`EXPLAIN` лимит строк применяется уже на стороне сервера MCP.
