# external-users

Внешние пользователи (без Битрикс24): вход по логину и паролю и экран «Бронирования» роли `viewer`
(ADR 0021). Пароли задаёт администратор (⚙ → внешние пользователи, `groups/external-passwords`).

| Маршрут | Доступ | Что |
|---|---|---|
| `POST /api/external/login {login,password,domain?}` | заголовок `X-Btx24-Standalone` | cookie `btx24_ext`; 5 неудач — пауза 15 мин, 20 попыток с IP за 15 мин |
| `POST /api/external/logout` | заголовок | удаляет сессию |
| `GET /api/external/session` | `ExternalAuthGuard` | логин, пояс портала, доступные группы |
| `GET /api/external/day?date&groupId` | `ExternalAuthGuard` | брони дня на ресурсах его групп, ресурсы, тех. окна |
| `GET /api/external/bookings/:id/products` | `ExternalAuthGuard` | товары сделки брони (токен приложения, кэш 5 мин) |

Инварианты:
- Только роль `VIEWER`; отключённый пользователь и технолог не получают сессию (технолог — TECH_DEBT).
- Портал — из сессии, не из запроса. Ресурсы — группы пользователя (`allGroups` — все). Чужая группа — 403.
- Поля карточки — по `visibleFields` (null — все): коды полей сделки, `CONTACT_ID` (клиент), `PRODUCTS`.
  Скрытое не отправляется с сервера. Неизвестные суммы/гости — null, не ноль.
- Брони — журнал приложения; пропавшие в Битрикс24 с открытым уведомлением не показываются.
- Оплаты (`payments`, новые сверху) и последняя оплата — оплаченные счета сделки (стадия `…:P`, `movedTime`, токен приложения, кэш 2 мин);
  у сделок без оплаченных счетов — последняя запись `DealPayment`. Статус оплаты экран пока не показывает.
- Смена пароля удаляет сессии пользователя и снимает паузу.
