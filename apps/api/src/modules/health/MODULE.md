# health

**Назначение:** `GET /api/health` — liveness/readiness приложения и доступности БД.
Используется healthcheck'ом Docker и MCP-инструментом `env_status`.

**Инварианты**
- Эндпоинт не требует авторизации и не возвращает секретов/конфигурации.
- Недоступная БД → `200` со `status: "degraded"`, а не 500: контейнер должен оставаться
  диагностируемым.

**Контракт:** `HealthResponse` из `@btx24/shared`.
