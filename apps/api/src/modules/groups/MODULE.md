# groups

**Назначение:** настройки групп (направлений) и приложения — данные нашей БД.

| Маршрут | Кто | Что |
|---|---|---|
| `GET /api/groups` | любой пользователь | его группы: роль, права, ресурсы (`MyGroupDto`) |
| `GET/POST /api/admin/groups`, `PUT/DELETE /api/admin/groups/:id` | админ приложения | список, создание, полная замена, архивирование |
| `GET/PUT /api/admin/settings` | админ приложения | переключатели сбора данных диалогов, список `AppAdmin` |

**Инварианты**
- Тела запросов — zod (`groups.schemas.ts`, `.strict()`: лишние поля вроде `portalId` отвергаются);
  `portalId` всегда из контекста пользователя.
- `PUT` группы — полная замена настроек, ресурсов и участников одной транзакцией.
- Удаление — архивирование (`archivedAt`), не физическое.
- Сбор текстов диалогов нельзя включить без сбора метаданных; оба по умолчанию выключены.
- Диапазоны дублируются CHECK-ограничением в БД (`WorkGroup_ranges`).
