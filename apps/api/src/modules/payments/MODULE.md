# payments — счёт и ссылка на оплату (ADR 0009)

- `PaymentsService` (api, токен сотрудника): `GET /api/payments/preview`, `POST /api/payments`,
  `GET /api/payments?dealId`. Право — `payment.send` в группе, чья воронка = воронка сделки
  (или группа брони). Создаёт смарт-счёт, пишет ID счёта (и стадию, если включено) в сделку,
  20 секунд ждёт ссылку.
- `PaymentFlow` — шаги после счёта, общие для api и worker: ссылка → поле сделки → сообщение
  клиенту → комментарий; ожидание → оплачено / срок вышел (снять бронь, аннулировать оплаты счёта).
- `PaymentJob` (worker, 30 с) доводит `link_pending` и `sent`; сбой заявки — `attempts++`, повтор.
- `GET /api/admin/invoice-meta` — воронки/стадии/поля смарт-счетов для ⚙ → группа → «Оплаты».

Инварианты: ссылку не логировать; срок оплаты — только если сообщение клиенту ушло; удалять
можно только оплаты счёта, созданного приложением (`AppCreatedEntity` `invoice` → `payment`);
бронь снимается только своя (политика записи).
