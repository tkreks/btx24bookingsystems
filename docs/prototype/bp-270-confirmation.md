# БП 270 «[БК] Изменение полей сделки и отправка сообщения клиенту» — разбор

Прочитан 2026-10-21 через REST (`bizproc.workflow.template.list`, токен приложения, только
чтение). Документ — сделка. Это эталон для переноса подтверждения брони в приложение (решение
владельца: по возможности без БП). Ссылки с параметрами и вебхуки в разборе не приводятся.

## 1. Тип бронирования — по товарам сделки
Переменная `tovary` = товары сделки (печатный вид). Ветки по вхождению подстроки:

| В товарах есть | Тип (`dealtype`) | Поле «Тип бронирования» `UF_CRM_1754995195231` |
|---|---|---|
| программа (см. ниже) | Программы | 86 «Программа» |
| «Суточная» | Суточная (программа = «Суточная аренда дома на воде») | 90 «Суточная» |
| «Почасовая» | Почасовая | 88 «Почасовка» |
| «Теремок» | Теремок | 92 «Теремок» |
| «Оплата сертификата» | Сертификат | 134 «Сертификат» |
| ничего | — уведомление менеджеру «Не определен тип бронирования… заполните товары», комментарий в сделке, **сообщение клиенту не отправляется** | — |

Программы (переменная `programm`): Алатырь, Спец программы, Мужской круг, Елань, ОБО,
Программа для влюбленных, Чистый четверг, Девичник.

## 2. Цепочка сообщений клиенту (открытая линия сделки)
Для «Программы», «Суточная», «Почасовая», «Теремок» — одинаковый порядок:
1. **Файлы с Диска** (ID файлов 92152 и 141098 — правила / меню, уточнить у владельца).
2. **Подтверждение брони** — текст свой для каждого типа (см. п. 3).
3. «Предзаказ вкусных блюд и напитков: …по телефону менеджера ресторана… (с 10.00 до 21.00)».
4. «Просим Вас предоставить информацию о количестве и размерах банного текстиля…» (женские
   XS–XL, мужские M–XXL).
5. «Уточните, пожалуйста, информацию для пропуска на парковочное место: номер и марку автомобиля.»
6. «Если у гостей есть аллергия на что либо, просим сообщить об этом в этом чате».
7. Комментарий в сделке.

«Сертификат» — одно сообщение «{Имя}, благодарим, оплата подтверждена!» + комментарий.

## 3. Подтверждение: переменные
`{=Document:CONTACT.NAME}` — имя контакта; даты и время визита — строковые поля
`UF_CRM_1754843339886` (дата начала), `UF_CRM_1754843349378` (время начала),
`UF_CRM_1754843362814` (дата завершения), `UF_CRM_1754843387505` (время завершения);
`{=Variable:programm}` — программа; `UF_CRM_1754826067667` — количество гостей;
**`UF_CRM_1754996940869` «Банный дом»** (список: 94 «Дом на воде 1» … 104 «Дом на воде 6»,
106 «Теремок»); `OPPORTUNITY` — стоимость.

Тексты по типам отличаются блоком «Включено в стоимость» (купели, текстиль, чай, сенные качели,
депозит на парение 10 000 / 15 000 / 20 000 ₽ и т. п.), правилом об опоздании, адресом и ссылкой
на навигатор. Длинные варианты «Рады приветствовать Вас в Банном комплексе „Алатырь“…» в
нескольких ветках записаны **в комментарий сделки**, а клиенту уходит короткий — уточнить у
владельца, какой актуален.
