# Интерфейс прототипа (эталон)

`app.html` — HTML шаблона `GET /booking-local/app` из экспорта flow Node-RED (узел `template`),
извлечён 2026-10-21 без изменений. Секретов в нём нет (проверено: ни адресов вебхуков, ни
токенов, ни e-mail). Сам экспорт flow (`node-red*.json`) в git не попадает — в нём настройки
и доступы прототипа.

Используется как образец для видов календаря (календарь / список / доступность), карточки брони
и блока «Настройка групп» (решение владельца: «как в прототипе»). Основные места:

| Что | Где в `app.html` |
|---|---|
| шапка: группы-вкладки, дата, переключатель вида, ⚙ | `<header class="top">` |
| виды: `calendarWrap`, `listWrap`, `availabilityWrap` | `<section id="appArea">` |
| карточка брони: даты, ресурс, поля сделки, товары, оплаты | `#bookingModal` |
| настройки групп, пользователи прямой ссылки, wazzup | `#settingsModal` |
| выбор разделов каталога | `#settingsSectionsModal` |
| логика | `<script>` после `<body>` |
