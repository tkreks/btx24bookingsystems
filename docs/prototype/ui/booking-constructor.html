Состояние:

Заметки дизайнера

Дополняют спецификацию docs/features/booking-constructor.md. Где расхожусь или предлагаю улучшение — фиолетовый блок «Предложение дизайнера».

1. Сетка и размеры

  • Окно: ширина до 760px, высота min(92dvh, 960px), радиус 18px, тень 0 24px 60px rgba(16,24,40,.16). Фон окна — --bg #f5f5f7, разделы — белые карточки: так свёрнутые строки читаются как «стопка», а активный раздел выделяется рамкой.
  • Шапка 52px: заголовок 16px/700, после «·» — группа и клиент приглушённо (--muted); справа — источник входа (пилюля «из чата», «из звонка»), «свернуть», «×».
  • Свёрнутая строка 44px (телефон 48px, CALL_CARD 40px): 22px значок | 156px название | сводка | «Изменить» (в спецификации 132px — см. предложения), отступы 0 8px 0 12px, промежуток между строками 6px, радиус 12px. Вся строка — одна <button>.
  • Активный раздел: рамка 1.5px --primary + ореол 0 0 0 3px rgba(0,122,255,.08), внешний отступ 4px сверху и снизу; заголовок 48px, 15px/700; тело — отступы 2px 14px 14px, промежуток между блоками 14px; низ раздела — «Далее →» (мягкая синяя кнопка, главная — в футере).
  • Контролы: высота 36px (CALL_CARD 32px), радиус 10px, рамка #d0d5dd, метка над полем 12.5px/500 #475467, промежуток метка–поле 5px, между полями 12px по вертикали и 14px по горизонтали. На телефоне шрифт в полях 16px (иначе Safari увеличивает страницу при фокусе).
  • Футер 56px, закреплён: слева живая сводка 13px (итог 15px/800), справа «Отмена» и главная кнопка. На телефоне — две строки: сводка, затем кнопки высотой 44px; снизу добавляется safe-area-inset-bottom.
  • Таблица товаров (ПК): 1fr | 100 кол-во | 90 цена | 108 скидка | 82 сумма | 28 ×, строка ≈48px, шапка 32px 11.5px --muted. Числа — tabular-nums, выравнивание вправо.

2. Цвета статусов

done #079455 / фон #ecfdf3 warning #dc6803 / фон #fffaeb / линия #fedf89 error #d92d20 / фон #fef3f2 / рамка #fda29b / текст #b42318 locked #98a2b3, пунктирная рамка empty — пунктирный кружок active #007aff
  • done — зелёная галочка в светлом кружке; сводка обычным текстом #344054.
  • warning — жёлтый треугольник, рядом со сводкой пилюля «тех. окно» (#fef0c7 / #b54708); рамка строки чуть желтеет.
  • error — красный круг с «!», полоса 3px слева, рамка #fda29b, фон #fffbfa, красная пилюля с текстом проблемы. Единственный статус, который тянет взгляд, — так и задумано.
  • locked — строка без фона с пунктирной рамкой, серый замок, текст-подсказка «Сначала выберите группу», курсор not-allowed, без «Изменить». В фокус клавиатуры не попадает (aria-disabled, но остаётся в дереве доступности — подсказку читает экранный диктор).
  • empty — пунктирный кружок, сводка «Не выбрано» серым.
  • Цвет никогда не единственный носитель смысла: у каждого статуса своя форма значка и текст в пилюле.

3. Состояния контролов

  • hover: строки и пункты — фон #f5f7fb; поля и карточки — рамка темнее (#98a2b3); тег раздела — рамка и текст primary.
  • focus (только :focus-visible): рамка primary + ореол 0 0 0 3px rgba(0,122,255,.18). Одинаково у кнопок, полей, чипов, строк разделов, тегов.
  • selected: карточки и чипы — рамка primary, фон rgba(0,122,255,.06–.10), текст #0b5cc4; у карточек — радиокружок с толстой синей рамкой.
  • disabled: прозрачность 50%, курсор not-allowed, рядом всегда текст «почему» (подсказка в низу раздела или title). Главная кнопка не отключается молча: «Далее» без выбранной сделки — отключена с подсказкой «Выберите сделку или «Новая сделка»».
  • изменено вручную: янтарный (#fdb022/#fffaeb) — цена товара («изм.»), формула, переписанная руками (точка у ƒ), и кнопка ↺ «вернуть».
  • по умолчанию: фиолетовая метка (#f4f3ff / #5925dc) — и у товара «по умолчанию · Баня 1», и у поля сделки. Один цвет = одно значение во всём окне.

4. Анимации

  • Сворачивание/раскрытие: grid-template-rows: 0fr → 1fr, 220ms ease; одновременно старый раздел сворачивается, новый раскрывается. После раскрытия — scrollIntoView({block:'nearest'}) заголовка, фокус — на первый незаполненный контрол раздела (или на поле, по которому кликнули в сводке ошибки).
  • Новая строка товара: вставляется вверх списка допов, фон #d6e8ff → прозрачный за 1.2s + полоса 3px primary слева, полоса держится, пока окно открыто (в макете — «Парение»). Счётчик тега обновляется без анимации.
  • Окно каталога: затемнение 150ms, окно — подъём на 8px + масштаб .985 → 1 за 180ms; на телефоне — выезд снизу.
  • Ошибка поля: рамка и фон краснеют без «тряски»; при «Проверить» с ошибками раздел П раскрывается, фокус — на первое пустое обязательное поле.
  • Всё отключается при prefers-reduced-motion: reduce.

5. Обязательные поля

  • Пометка: красная * сразу после метки (без пробела, 700), у контрола aria-required="true"; в заголовке П справа — «обязательных: 3». Пока поле не трогали, оно не красное.
  • Подсветка после ухода с раздела / потери фокуса пустым / «Проверить»: рамка #d92d20, фон #fef3f2, метка красная, под полем «⚠ Обязательное поле» 12px. Для чипов — красная обводка и фон вокруг группы; для степпера — красная рамка степпера. В паре «2 в линии» краснеет только пустая ячейка.
  • Свёрнутый П с ошибкой: красный «!», полоса слева, пилюля «Не заполнено 2: Гостей, Программа» (дальше «+N»). Клик по строке — раскрыть П и поставить фокус на первое из них (состояние E′).
  • Проверка с ошибками не открывается: строка «Проверка» — locked с текстом «Сначала заполните: Гостей, Программа»; кнопка «Проверить» в футере активна и ведёт к первой ошибке.
  • В «чеке» обязательные поля — полужирным значением, необязательные — обычным; пустые необязательные не показываются.
  • Тексты: «Обязательное поле» · «Укажите число гостей» (для степпера, если 0) · «Выберите программу» · «Не заполнено 2: Гостей, Программа» · «Сначала заполните обязательные поля сделки».

6. Товары, допы и оплата

  • Сверху — плашка-источник: для новой/пустой сделки синяя «Подставили товары по умолчанию для Баня 1», для сделки с товарами — жёлтая «Изменения заменят товары сделки #678» с кнопкой «Вернуть товары сделки».
  • Панель «Допы» — серый блок: поиск по каталогу (Enter или 2+ символа → окно каталога с этим запросом) + «Весь каталог»; ниже теги разделов. Тег с выбранным — мягкая синяя заливка и кружок-счётчик (число позиций, не штук). Порядок тегов — из ⚙ группы; первые 4, остальные под «Ещё ▾». Клик по тегу открывает окно каталога сразу на этом разделе.
  • Строка: название 13.5px/600, под ним мета 11.5px: «по умолчанию · Баня 1 · = длительности» или «каталог 600 ₽ ↺». Изменённая цена — янтарное поле с ярлыком «изм.» на рамке; подсказка title «Каталог: 600 ₽». Скидка — поле + переключатель единиц «%/₽» (клик меняет). Со скидкой — старая сумма зачёркнута над новой.
  • Количество «Баня, час» следует за длительностью (4 ч → 4), пока его не правили руками; после правки мета меняется на «изменено вручную», ↺ возвращает связь.
  • Пустое состояние: «Товаров пока нет» + «Добавьте из каталога или выберите раздел выше». Кнопки каталога, пока не загружены товары сделки, — отключены, подсказка «Загружаем товары сделки…», вместо таблицы — 3 строки-скелета.
  • «Бронь и оплата»: тип брони — карточки (≤3 вариантов) или select (больше); способ оплаты — сегмент; сумма предоплаты — деньги; переключатель «Ссылку на оплату — в чат после создания». «Гостей» — только если в группе нет поля-роли (в примере оно есть в П, поэтому здесь не показано).

7. Окно каталога (и доп. услуг)

  • Нативный <dialog>, 660×до 640px, сверху 64px от края окна. Шапка: «Каталог · Бани» + поиск (автофокус); слева разделы 184px («Все 26», затем разделы с числом товаров и синим кружком числа выбранных позиций; вложенные — с отступом); справа товары.
  • Строка товара 48px: название + (при поиске) подпись раздела и подсветка совпадения; цена (без цены серым); «+» или степпер. Выбранная — фон rgba(0,122,255,.06) + полоса 3px слева. «−» до нуля убирает позицию из брони.
  • Доп. услуги (D′) — тот же компонент, у услуг под названием длительность и исполнитель («40 мин · банщик»); у услуги «без цены» после добавления в таблице цена пустая и подсвечена янтарным «укажите цену».
  • Футер: «Выбрано: 4 позиции · 17 310 ₽» — те же итоги, что и в таблице (с ручными ценами и скидками), плюс «Готово». Esc и «×» закрывают только окно; выбранное уже применено (без «Отмены» внутри окна — меньше потерь).
  • Пустой поиск: «Ничего не нашли по «…»» + «Искать во всех разделах» (если стоял фильтр раздела).
  • Телефон: окно-лист снизу на 92% высоты, разделы — лента чипов, цена — под названием.

8. Поля сделки

  • Блоки с заголовком: капс 11.5px/700 #475467, разрядка .05em, тонкая линия до правого края; справа в заголовке — уточнение («из настроек группы»).
  • Число «гостей» — степпер 36px (− поле +), пустое значение «—»; деньги — разделители тысяч, «₽» справа внутри поля, выравнивание вправо; список ≤5 коротких — чипы, иначе select; да/нет — сегмент «Да | Нет | —» («—» = не задано); дата — поле + ссылки «сегодня» / «дата брони»; формула — серое поле со значком ƒ и меткой «авто»; изменённая вручную — белое поле, янтарная точка у ƒ, метка «вручную» и кнопка ↺; по умолчанию — фиолетовая метка у подписи; многострочный текст — всегда во всю ширину.
  • «Сумма сделки» — не поле ввода: пунктирная плашка «17 310 ₽ · из товаров» со ссылкой «Товары →» (открывает Т).
  • Только чтение — одной серой строкой «подпись: значение» внизу; поля, которые заполнит приложение, перечислены там же одной фразой («ID брони, дата брони, ссылка на оплату — заполнит приложение»).

9. Пустые, загрузочные и ошибочные состояния

  • Раздел, чьи данные грузятся, — скелеты (полосы 12px, мерцание 1.3s) по форме будущего контента; в свёрнутой строке — «Загружаем…» вместо сводки.
  • Нет сделок у клиента: в К сразу выбрана карточка «Новая сделка», раздел свёрнут, открыт Г.
  • Нет свободного времени в дне: под шкалой — «На пн 27.10 всё занято» + «Ближайшее свободное: вт 28.10 12:00 →».
  • Свежая занятость: Р становится error, пилюля «Баня 1 заняли 14:00–16:00», в шкале занятый кусок поверх выбора.
  • Ошибки создания: 409/стоп → открыть Р с красной плашкой; 503 → в футере «Повторить» (тот же ключ идемпотентности); «уже создаётся» → «Проверить результат».

10. Доступность и клавиатура

  • Строка раздела — <button aria-expanded aria-controls>; тело — role="region" aria-labelledby. Сводка и статус читаются в названии кнопки: «Ресурс и время, предупреждение: тех. окно. Баня 1, 14:00–18:00, 4 ч. Изменить».
  • Карточки сделок/групп/типа брони — role="radiogroup" + role="radio" aria-checked, стрелки ↑↓←→ двигают выбор; чипы списка — тоже радио-группа; сегмент да/нет — aria-pressed.
  • Ошибка поля — aria-invalid="true" + aria-describedby на текст «Обязательное поле»; при «Проверить» — aria-live="polite" сообщение «Не заполнено 2 поля».
  • Шкала: клавиатурная альтернатива — «Начало» и «Длительность» над шкалой; полосы занятости — title/aria-label «Баня 2, занято 12:00–15:00».
  • Клавиши: Enter в разделе = «Далее» (кроме textarea), Ctrl/⌘+Enter = главная кнопка футера, Esc — закрыть окно каталога, второй Esc — спросить «Закрыть конструктор? Данные не сохранятся» (если что-то введено).
  • Контраст: серый текст #6b7280 на белом 4.8:1; подсказки locked #98a2b3 используются только вместе с тёмным названием раздела.

11. CALL_CARD (карточка звонка)

  • Узкая колонка ~380–480px: включается телефонная раскладка, но плотнее — строки 40px, контролы 32px, промежутки 8px.
  • Футер переносится вверх (под шапку): во время разговора нижний край карточки звонка закрыт панелью телефонии.
  • К открыт для подтверждения: выбранная сделка (по звонку) отмечена, «Далее» сразу активна.
  • Время — компактно: вместо шкалы список свободных окон по ресурсам («Баня 1: 14:00–18:00, после 21:30»), шкала — по кнопке «Шкала» в окне.
  • Окно каталога — на всю карточку; товары только карточками.

12. Предложения дизайнера

  • Буквы К/Г/Р/Т/П — только для документации. В интерфейсе — словесные названия и значок статуса; буквы не несут смысла для менеджера и путаются с инициалами.
  • Поиск в панели «Допы» сначала показывает выпадающий список из 6 совпадений прямо под полем (Enter — добавить первое, ↑↓ — выбор), а «Все результаты →» открывает окно каталога. Частый сценарий «добавить чай» — без окна.
  • Счётчик на теге и в окне — число позиций, не штук (иначе «Веники · 3» при 2 дубовых и 1 эвкалиптовом читается как «три вида»). Зафиксировать в спецификации.
  • В итогах — ссылка «Скидка на всё…» (одна скидка % на все строки, кроме «по умолчанию» по выбору). Сейчас менеджер ставит скидку построчно.
  • Услуга «без цены» после добавления: цена пустая и подсвечена янтарным «укажите цену» — предупреждение на проверке («1 товар без цены»), но не блокирующая ошибка.
  • В свёрнутом П с ошибкой каждое имя в пилюле — отдельная ссылка: клик по «Программа» открывает П и ставит фокус именно на «Программу».
  • «Создать бронь» с предупреждениями — без отдельного чекбокса «Я видел предупреждения»: подпись в кнопке «· с предупреждениями: 1» и жёлтый блок над ней достаточны; лишний клик раздражает на каждом тех. окне.
  • В шкале тех. окно — продолжение выбора янтарной штриховкой; если оно залезает на чужую бронь, штриховка темнее с обводкой, и в предупреждении — точное пересечение («пересекается на 15 мин с бронью 18:15»).
  • Цвет сделки (🟢🟡🔴) на карточке дублировать словами: «пустая», «поля заполнены», «есть бронь 03.11» — цвет сам по себе не читается дальтониками и экранным диктором.
  • «Свернуть» в шапке — сворачивает окно в плавающую плашку справа внизу «Новая бронь · Баня 1 · 14:00 ↗», чтобы заглянуть в календарь/чат и вернуться без потери данных (черновик живёт до закрытия вкладки).
  • Экран результата показывать при частичном сбое и при «ссылка на оплату не отправлена»; при полном успехе — закрывать окно и показывать тост «Бронь #555 создана · Открыть», без лишнего экрана (совпадает с вопросом 5 спецификации).
  • Название раздела в строке — «Товары и оплата» (а не «Товары, допы и оплата»), колонка названия — 156px вместо 132px: при 132px не помещаются ни «Товары, допы и оплата», ни «Ресурс и время» полужирным 14px; сводка от этого не страдает (у Т она самая длинная, ≈300px, и помещается в окне 668px).
  • На телефоне теги разделов — горизонтальная лента без «Ещё ▾» (скролл естественнее, чем выпадающее меню на узком экране).
