Дизайн-решения

Сетка и ритм

  • Контейнер мастера до 1080px, боковой отступ --pad: 22px на ПК, 16px на телефоне (≤720px). Шаг = карточка (--radius 16px, рамка --line, тень 0 1px 2px).
  • Вертикальный ритм кратен 4: 6 / 8 / 12 / 16 / 20px. Между полями 14px, между колонками пары 16px (как .df-row.pair).
  • Списки выбора — CSS grid auto-fill, minmax(…): сделки ≥300px, ресурсы ≥220px, группы ≥220px — сами раскладываются в 1–3 колонки без медиазапросов.
  • «Дата и ресурс»: 1fr + 300px (календарь + липкая карточка слота); ≤900px — карточка уходит под календарь.

Контролы

  • Высота любого контрола — 40px (--ctl): поля, селекты, кнопки, сегменты, степпер количества. Компактные (внутри строк/диалогов) — 32px.
  • Радиус: поля и кнопки 10px, карточки выбора 12px, плитки групп 14px, шаг/диалог 16px, бейджи и чипы — pill.
  • Подпись поля сверху 12.5px --f-label, текст поля 15px (16px на телефоне — без автозума iOS). Фокус — рамка --primary + кольцо 3px --f-focus.
  • Выбор одного из N — карточки с радиоточкой (.wz-dot), выбранная: рамка 1px + внутренняя тень 1px --primary, фон rgba(0,122,255,.04). Двоичный/тернарный выбор — сегмент .wz-seg.

Телефон (390px)

  • Степпер: только номера, подпись — у активного шага; горизонтальная прокрутка внутри степпера.
  • Все сетки в 1 колонку; пары полей — одна под другой. Календарь прокручивается по горизонтали внутри своего блока (колонка 132px, часы липкие слева) — у страницы горизонтальной прокрутки нет.
  • Строка товара превращается в карточку: название + удалить; кол-во и цена в 2 колонки; скидка; сумма строкой.
  • Нижняя панель: сводка в 1–2 строки (второстепенное скрыто), кнопки во всю ширину; учтён safe-area-inset-bottom. Диалог — bottom sheet.
