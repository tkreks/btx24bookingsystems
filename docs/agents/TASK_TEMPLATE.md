# Шаблон задачи

Копировать в `.agent/tasks/<task-id>.md` (локально, в `.gitignore`) при старте нетривиальной
задачи. MCP-инструмент `get_task_state` читает этот файл по `task_id`.

```markdown
# Task <id>
Цель (1–2 предложения):
Затронутые модули / workspaces:
Ограничения (что явно нельзя менять):
Критерии готовности (проверяемо):
Подтверждённые пути и символы:
План (если нужен):
Прогресс / следующий шаг:
Открытые вопросы:
```

- Ограничения пишем явно, даже очевидные («не трогать схему», «не менять контракт API»).
- Критерии — проверяемые факты (команда, ответ эндпоинта), а не «сделать хорошо».
- Чекпоинт — подсказка для продолжения, не источник истины: после перерыва сверить с
  `git diff` и файлами.
