# ADR 0011: Снимки дашборда и живые данные бронирования

Статус: принято, 2026-10-24. Основание: требование владельца.

Дашборд использует stale-while-revalidate через sessionStorage текущей вкладки, с явным
списком разрешённых API-ресурсов. Изоляция по проверенному порталу, сотруднику, правам и
параметрам запроса. Срок снимка — пять минут; каждый вход всё равно обновляет его через API.
Опрос 30 секунд, чаты 15 секунд; фокус/сеть/мутации инициируют раннее обновление.

Календарь, список броней и доступность не сохраняют снимки. Обновление прямыми запросами
каждые 15 секунд. Завершённые ответы серверного дашборда также не удерживаются по TTL:
это исключает косвенное кэширование броней через базовую часть дашборда. HTTP no-store.
Остаётся только объединение одновременно выполняемых одинаковых серверных запросов.

Плюсы: быстрый повторный вход в дашборд, отсутствие полной перезагрузки и сброса формы,
явная индикация синхронизации. Цена: периодический REST-трафик и ограниченная интервалом
свежесть. Фоновый опрос выключен в скрытой вкладке; запросы одного ресурса не пересекаются.
Redis/новая таблица не требуются; правила создания брони и tenant/access guards неизменны.
