Показатели по строкам: брони сегодня, оплаченные сделки, упущенные звонки,
новые брони, удалённые брони, уникальные клиенты.

Миграция 20261025000300 однократно заменяет прежние сохранённые раскладки всех сотрудников
портала владельца этим снимком, включая изменённые вручную. Другие порталы не затрагиваются.
Новые сотрудники и кнопка «Сбросить» получают тот же вид. ID блоков нормализованы по типу:
порядок, размеры и показатели совпадают со снимком, случайные суффиксы личных ID не нужны.

Дальнейшая личная настройка доступна; изменения Максима после снимка не распространяются
на остальных. Данные и доступ к ним остаются персональными по существующим правам.

## Шкала броней (2026-10-25)
Каждый час выбранного дня подписан и отмечен вертикальной линией. Дата выбирается в самом
блоке; по умолчанию сегодня, полные сутки00:00–24:00. День и периоддо7дней имеют разную
разбивку: часы либо суточные ячейки (любая бронь = занятый день). Стопы серые и не позволяют
создать бронь; строки21px. Выбор группы/ресурсов — карточками мастера брони. Подробнее
[Шкала и поиск клиентов](dashboard-timeline.md).

## Окна «Добавить блок» и «Заменить блок» (2026-10-30)
«Добавить блок» — широкое окно (до 1100px, на телефоне — во весь экран): слева разделы каталога
(«Все блоки», «Показатели», «Списки», «По дням и сравнение», «Контроль») со счётчиками, сверху
поиск по названию, подсказке и разделу (без учёта регистра и «ё»), в центре — карточки блоков со
схематичным эскизом (число, строки, график, шкала, таблица KPI, журнал, мессенджеры, пары дублей…;
эскиз под каждый тип — `BLOCK_PREVIEWS` в `apps/web/src/dashboard/block-catalog.ts`, рисует
`BlockPreview.tsx` токенами темы). Блоки, уже стоящие на дашборде, видны с отметкой «На дашборде»
и не добавляются. Клик по карточке — справа (на телефоне — снизу) крупный эскиз, описание, выбор
ширины на мини-сетке ряда из 6 колонок и «Добавить на дашборд»; двойной клик или Enter — добавить
сразу с шириной по умолчанию. Стрелки/Home/End — по карточкам, Escape — закрыть. «Заменить блок» —
те же карточки и поиск, разделы «На панели — поменяться местами и размерами» и «Не выведены · …».
