# Встройка сделки: «Чат с клиентом · Календарь · Новая бронь»

Решение владельца 2026-10-26 (заменяет «Чат · Сделка · Календарь» от 2026-10-25). Из карточки сделки
приложение открывается стартовым экраном (`apps/web/src/deal/DealHome.tsx`). Открытие не из сделки —
как раньше (дашборд).

- **Чат с клиентом** — блок с числом чатов клиента сделки (`GET /api/openlines/deal-chats/:dealId`,
  правами сотрудника) и строками, как в «Последних сообщениях» дашборда (канал, аватар, имя, пузырь,
  непрочитанные) с теми же кнопками: «!», сделка, перейти в чат, скрыть с дашборда. В блоке до трёх чатов,
  остальные — «Все чаты» / «Ещё чатов: N»: «Чаты» с вкладкой клиента сделки (есть только при входе из
  встройки).
- **Ошибка канала Wazzup** в чате клиента (уведомление «канал выключен» в последнем сообщении) — в блоке
  чата красное предупреждение и сразу поиск клиента по мессенджерам по номеру (`MessengerSearchButton
  autoStart`, клиенту ничего не уходит). Найден — нажатие на значок открывает переписку или первое
  сообщение через свою линию; новый чат открывается в «Чатах».
- **Календарь** — календарь броней.
- **Новая бронь** (право `booking.create`) — мастер брони поверх календаря. Сначала проверка броней
  сделки (`/deals/:id/bookings`; снятая/удалённая, известная только по полям сделки, не считается). Есть
  бронь — предупреждение «По этой сделке есть бронирование»: «Создать новую сделку» (`POST
  /api/deals/:id/new-deal`) или «Игнорировать» — мастер брони. Не удалось проверить — мастер брони.
- Экран «Сделка» (карточка и таймлайн, `GET /api/deals/:dealId/overview`) со стартового экрана убран;
  код и API остались.
- Кнопки строки чата (здесь и на дашборде): сделка — портфель, «Перейти в чат» — пузырь со стрелкой,
  «Скрыть с дашборда» — перечёркнутый глаз.

# «Чаты»: «+ Добавить»

Кнопка «Мессенджеры групп» (📱) убрана; на её месте — зелёная «+ Добавить» (право писать). Окно
«Новый диалог» (`NewDialogDialog`): номер телефона (все мессенджеры) или логин Telegram (`@имя`,
`t.me/имя`) → у каждого подключения статус проверки (проверяем / найден / не найден / недоступно) →
«Начать чат». Есть чат в своей линии — откроется он; нет — окно первого сообщения. Проверка ничего
не отправляет клиенту.
