# Встройка сделки: чаты · шкала броней · быстрые действия

Решение владельца 2026-10-26 (заменяет «Чат с клиентом · Календарь · Новая бронь» того же дня).
Из карточки сделки приложение открывается экраном из трёх блоков в стиле дашборда
(`apps/web/src/deal/DealHome.tsx`). Открытие не из сделки — как раньше (дашборд).

- **Слева — чаты клиента** (`GET /api/openlines/deal-chats/:dealId`, правами сотрудника). Больше одного —
  список строками «Последних сообщений» дашборда («!» и «⋮»: сделка, перейти в чат, скрыть с дашборда);
  нажатие открывает только чат, к списку — «назад» слева сверху. Чат один — сразу он, без «назад».
  Ошибка канала Wazzup — в списке красное предупреждение и сразу поиск клиента по мессенджерам.
- **Справа сверху — шкала броней** (`ResourceTimelineBlock` дашборда): группы воронки сделки
  (`MyGroupDto.dealCategoryId` = воронка сделки из `/deals/:id/bookings`; не определилась — все группы
  с календарём), дата с ‹ ›, «Сегодня», масштаб, переключатель групп кнопками рядом с заголовком.
  Клик по свободному времени — мастер брони по этой сделке.
- **Справа снизу — быстрые действия:**
  1. **Ссылка на оплату** (`payment.send`) — мастер `PaymentLinkWizard`: вид (предоплата/доплата),
     основание, сумма (расчёт `/payments/preview`, можно изменить), срок оплаты в часах (1–24, пусто — без
     срока; по умолчанию — срок группы) → текст клиенту, по умолчанию «Просим Вам произвести оплату
     {{СсылкаНаОплату}}» (можно изменить) → `POST /payments` с `purpose`, `timeoutHours`, `message`.
     Счёт, ссылка, срок и отслеживание — прежние (ADR 0009); см. `apps/api/src/modules/payments/MODULE.md`.
  2. **Мастер бронирования** (`booking.create`) — поверх встройки; если по сделке уже есть бронь —
     прежнее предупреждение «Создать новую сделку / Игнорировать».
  3. **Отправить шаблон** — открывает чат клиента (если открыт список — самый свежий чат) и окно «Шаблоны»;
     шаблон вставляется в поле, отправляет менеджер.
- Экраны «Сделка» (`/deals/:dealId/overview`) и «Календарь» из встройки не открываются; код остался.

# «Чаты»: «+ Добавить»

Кнопка «Мессенджеры групп» (📱) убрана; на её месте — зелёная «+ Добавить» (право писать). Окно
«Новый диалог» (`NewDialogDialog`): номер телефона (все мессенджеры) или логин Telegram (`@имя`,
`t.me/имя`) → у каждого подключения статус проверки (проверяем / найден / не найден / недоступно) →
«Начать чат». Есть чат в своей линии — откроется он; нет — окно первого сообщения. Проверка ничего
не отправляет клиенту.
