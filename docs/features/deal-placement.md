# Встройка сделки: «Чат · Сделка · Календарь»

Решение владельца 2026-10-25. Из карточки сделки приложение открывается стартовым экраном с тремя
большими кнопками (`apps/web/src/deal/DealHome.tsx`). Открытие не из сделки — как раньше (дашборд).

- **Чат** — «Чаты» с дополнительной вкладкой «<Имя клиента>» перед «Все / ждут ответа / брони / ждут
  оплату»; она открыта по умолчанию. В ней — чаты открытых линий самой сделки и всех её контактов
  (`GET /api/openlines/deal-chats/:dealId`, правами сотрудника). Вкладка есть только при входе из
  встройки сделки: в «Чатах» из дашборда или меню её нет. Пусто — ссылка «Начать новый диалог».
- **Сделка** — карточка (стадия, сумма, клиент с телефонами, ответственный, дата создания) и таймлайн
  действий всех сотрудников: создание и смены стадий, дела (звонки, чаты, письма, задачи), комментарии
  таймлайна CRM и журнал приложения по сделке и её броням (`GET /api/deals/:dealId/overview`). Права —
  токен сотрудника: нет доступа к сделке в CRM — ошибка, а не чужие данные. У истории стадий нет автора.
- **Календарь** — сначала проверка броней сделки (`/deals/:id/bookings`; считаются брони, которые есть
  в модуле бронирования — снятая/удалённая, известная только по полям сделки, не считается). Есть —
  предупреждение «По этой сделке есть бронирование»: «Создать новую сделку» (`POST
  /api/deals/:id/new-deal`: клиент, компания и воронка исходной, ответственный — сотрудник; открывается
  карточка новой сделки) или «Игнорировать» — календарь как раньше. Не удалось проверить — календарь.
  В календаре из сделки — кнопка «‹ Сделка» назад к трём кнопкам.

# «Чаты»: «+ Добавить»

Кнопка «Мессенджеры групп» (📱) убрана; на её месте — зелёная «+ Добавить» (право писать). Окно
«Новый диалог» (`NewDialogDialog`): номер телефона (все мессенджеры) или логин Telegram (`@имя`,
`t.me/имя`) → у каждого подключения статус проверки (проверяем / найден / не найден / недоступно) →
«Начать чат». Есть чат в своей линии — откроется он; нет — окно первого сообщения. Проверка ничего
не отправляет клиенту.
